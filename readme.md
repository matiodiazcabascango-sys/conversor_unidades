# Conversor de unidades

## Descripción

Aplicación de consola que realiza conversiones de unidades, pasando
del Sistema Internacional (SI) al Sistema Usual de los Estados
Unidos (USC).

## Objetivo

Facilitar la conversión rápida entre unidades del sistema métrico y
el sistema imperial mediante un programa de consola simple.

## Funcionalidades

- Conversión de longitud: kilómetros a millas, metros a pies.
- Conversion de Masa: Kilogramos a libras, kilogramos a onzas.
- Conversion de temperatura: Celsius a fahrenheit, Celcius a kelvin.

## Instalación y ejecución

1. Clonar el repositorio:
   
   git clone https://github.com/matiodiazcabascango-sys/conversor_unidades
   
2. Navegar al directorio del proyecto:
   
   cd conversor-unidades
   
3. Verificar que Python 3 esté instalado:
   
   python --version
   
4. Ejecutar el archivo principal:
   
   python main.py
