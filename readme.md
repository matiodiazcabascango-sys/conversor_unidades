## Conversor de unidades

## Descripcion
Aplicacion de consola que realiza conversiones de unidasdes, pasando del sistema SI a USC

## Funcionalidades
**Conversion de longitud* cambiar de kilometros aa millas

## Tecnologias utilizadas
**Lenguaje** python 3
**Editor de codigo* Visual Studio Code
**Control de versiones** Git
**Alojamiento de codigo** GitHub

## estructura del proyecto
```text
conversor-unidades/
|
|—— .gitignore   # Archivos omitidos por el control de veriones
|—— .vs code #Configuracion del editor personal
|—— configuracion.tmp # Archivos temporales
|—— main.py #Script principal del proyecto
|—— prueba.log #Un entono para realizar pruebas
|__ readme.md #Documentacion del proyecto
```

##Instalacion y ejecucion
1. clonar el repositorio
git clone {url del repositorio}
2. navergar el directorio
cd conversor_unidades
3. Instalar requisitor
Python 3, para verificar en la consola python  --version
4. Ejecutar el archivo principal
En la consola --> python main.py
